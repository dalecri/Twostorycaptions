One-time setup

Cat tags and archiving need two extra columns in your Supabase ttt_clips table — they're working locally for now, but won't survive a reload until this is run. Paste this once into the Supabase SQL editor:

alter table ttt_clips add column if not exists cat_tags text;
alter table ttt_clips add column if not exists archived boolean default false;
